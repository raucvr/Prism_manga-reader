# Prism v3 报告（2026-10-23）

> 历史报告（v3）。表中的 `output/` 任务目录是本地运行记录，不在仓库中；评测题目见 `eval/quizzes/`，当前版本见 `docs/v4-report.md`。

所有者的要求：读完漫画至少要有读完论文摘要的程度，关键数据放进漫画里作证，并且用生动的故事讲出来。

## 0. 结论速览

- v2 的问题出在架构：所有文字都让 Seedream 画进图里。为了画对，每格只能放一句短话，数字和图表都不能入画，画面只剩比喻道具。
- v3 让 Seedream 只画没有字的画，文字由程序用真字体排版，图表由程序按论文的精确数字绘制。剧本改成"查证论文结论"的故事。同一套画面同时排出中英文两版。
- 独立读者只看图片，回答按摘要出的固定题目。题目、读者和打分方式都和 v2 基线相同：

| 论文 | v2 | v3 第一轮 | v3 第二轮 | v3 第三轮 |
|---|---|---|---|---|
| Attention（英） | 72% | 94% | 89% | 94% |
| BERT（中） | 45% | 85% | 100% | 85% |
| CoT（中） | 69% | 94% | 94% | 94% |
| BatchNorm（英） | 61% | 100% | 78% | 94% |
| 平均 | 62% | 93% | 90% | 92% |

- 最终版本（四篇各一份，中英双语）：

| 论文 | 任务 | 摘要题 | 答案来自图中图表 | 故事性 | 数据作证 |
|---|---|---|---|---|---|
| Attention | `output/20261023_032115_b4f1` | 94% | 4 题 | 6 | 7 |
| BERT | `output/20261023_032115_c491` | 85% | 4 题 | 6 | 8 |
| CoT | `output/20261023_035202_c264` | 100% | 2 题 | 6 | 5 |
| BatchNorm | `output/20261023_032115_bed6` | 94% | 2 题 | 7 | 7 |
| 平均 | | 93% | 3 题 | 6.3 | 6.8 |

  CoT 用的是第三轮之后修好"就近对齐"再跑的一次（第 5 节）；其余三篇是第三轮。四篇都用最终的排版代码免费重排过。
- 读者从画面中的图表或表格里找到答案的题数，从 v2 的 0 题，变成 v3 每轮每篇 0 到 5 题。
- 读者评分：故事性从 4 到 5 分升到 6 到 7 分。"数据作证"从 4 分升到 7 到 9 分；只有关键图表被删掉的那几次掉到 2 到 3 分（见第 4 节）。
- 注意：不看漫画、凭记忆作答的对照组四篇都是 100%。这四篇论文很有名，读者模型本身就熟悉，所以绝对分数可能偏高。但 v2 用的是同一批读者、同样的条件，分数低得多，提升是真实的。
- 成本：一篇 14 到 19 格的漫画，中英双语合计 $1.0 到 $1.5，用时 14 到 20 分钟（四篇并行，Seedream 快速模式关闭）。v2 单一语言每篇 $1.2 到 $1.6。
- 后端测试从 974 个增加到 1475 个，全部通过；前端类型检查和生产构建通过。

## 1. v2 为什么不行

逐格看完 v2 的成品后发现：

- 每格只有一个短气泡加一句旁白。机制没讲清，结果没有数字，更没有对比基线。
- 画面上是玩具火车、积木、发光石头这类比喻道具，和论文内容的联系要靠读者猜。
- 之前的覆盖率评分把阅读器里图片下方的文字也算了进去，高估了漫画本身。只看图片时，摘要题得分只有 45% 到 72%，没有一道题的答案来自图表。

## 2. v3 架构

```
PDF → 提取 → 摘要拆成结论 → 故事剧本（含图表规格）→ 程序检查与修正 → 事实核查 → 摘要测验 → 清除无据数字 → 翻译
                                                                                                   ↓
阅读器 ← 中英两版成品 ← 排版文字、绘制图表 ← 定位头部和白板 ← Seedream 画无字画面 ←────────────────────┘
```

| 环节 | 做法 | 文件 |
|---|---|---|
| 剧本 | 开场 → 论文结论清单（Nezu 用浆果挞打赌）→ 旧方法的问题 → 核心想法 → 机制 → 逐条用数据验证 → 回到例子 → 作者自己说的局限 → 结论清单逐条打勾。尽量用论文自带的例子贯穿全篇。 | `services/storyboarder_v2.py`（`build_v3`） |
| 图表 | 柱状图、表格、流程图、对比、注意力连线、清单。数值必须是论文原样的数字并附原文引用。论文的结果只标亮一根，最强的旧系统标成基线，差值由程序计算（+2.04、约 1/5.2）。 | `services/boards.py` |
| 数字核对 | 每个图表数值都要在论文原文中找到出处；每句对话和旁白里的数字也要能在论文里找到。 | `services/evidence.py` |
| 剧本检查 | 字数上限，对比柱必须写出系统名，一张图只有一个口径（不能把半监督和仅 WSJ 数据混在一起），对话中的差值必须和图一致，开场和结尾必须出现贯穿例子，禁止"证明了""完美"等夸大措辞，禁止会被画出乱码的道具（写字板、时钟、写着词的卡片）和人形道具（机器人、玩偶）。问题交给修正环节，最多两轮。 | `lint_v3` |
| 摘要测验 | 读者模型只看"教学格"（不算开头和结尾的清单）回答摘要题，评分模型打分。有任何一条结论没讲到，就针对它补写一次。 | `services/abstract_quiz.py` |
| 兜底 | 修正后仍不在论文里的数字，所在句子直接删除。 | `scrub_unsupported` |
| 画面 | 提示词要求整张画不出现任何文字。场景格顶部留出空白，图表格画一块大的空白白板。视觉模型返回头部位置、白板四角、画面上的字、多出的角色，有问题就带着反馈重画，最多 3 次。 | `services/panel_renderer.py`、`services/art_check.py` |
| 排版 | 旁白框和对话框按阅读顺序排，不遮脸，尾巴指向说话人；尾巴被白板挡住时加名字标签。图表画进白板的空白区域。字号按手机屏幕设定。 | `services/lettering.py` |
| 双语 | 英文剧本定稿后翻译成中文，数字逐句锁定，角色名保留英文。同一张画排出 `panel_NN.jpg` 和 `panel_NN.<语言>.jpg`。阅读器工具栏有"中 / EN"切换。 | `services/jobs.py`、前端 `Reader.tsx` |
| 免费重排 | 保存原画 `art_NN.jpg` 和定位结果 `grounding_NN.json`。`POST /api/jobs/{id}/relayout` 用最新的排版和图表代码重排一个已完成的任务，不花画图费。 | `services/jobs.py`、`tools/relayout.py` |

角色设定图去掉了标注文字（`config/character_images/clean/`）。Nezu 的描述改成和设定图一致：拿着浆果，不是写字板。原型里的乱码字就是写字板引出的。

## 3. 评测方法

- 题目：每篇 8 到 10 道，按摘要的每句话出题，事先写好，评测时固定不变（现在放在 `eval/quizzes/`）。
- 读者：独立代理，只能打开漫画图片，不许打开剧本和论文，不许用对这篇论文的已有了解；答不出就写"未展示"。每题注明答案来自图表、图中文字还是没有出现，并写出格号。
- 打分：另一个代理按标准答案打分，1、0.5、0；数字必须精确，"含集成模型""单模型"这类限定词必须保留。
- 对照组：一个代理不看漫画、凭记忆回答四篇的题目，再按同样方式打分，四篇都是 100%。
- 每一轮的读者意见（看不懂、看不清、分不清谁在说话）都用来改下一轮。

## 4. 三轮改了什么

| 轮次 | 发现的问题 | 修改 |
|---|---|---|
| 试跑（只写剧本，7 次） | 句法分析图把不同口径的结果直接相减；训练成本差值显示成"−9.7×10¹⁹"；"证明了"等夸大措辞；Nezu 的写字板 | 只有剧本标出基线才显示差值；大数改显示倍数；措辞检查；设定图去字、改写 Nezu 描述 |
| 第一轮 | 读者分不清谁在说话；角色没介绍名字；术语没解释；局限放在结尾例子前面；CoT 的关键对比图只剩一根柱子（"55^(a)"的脚注被误当成乘方）；BatchNorm 的步数图因为"31.0M"写法被删 | 名字标签；开场介绍角色；术语规则；结尾例子移到局限之前；修正脚注和 K/M/B 量级解析；中文数字改用无衬线字体（避免"1"像"l"） |
| 第二轮 | CoT 的图仍只有一根柱子（模型从图 2 读数，标签和数值在提取文本里不在同一行）；BatchNorm 把"百万"写进单位栏；Attention 漏掉最强的旧单模型 | 单位栏里的量级参与核对；核对失败时附上论文里同时含名称和数字的原句；人形道具和"写着词的卡片"禁用 |
| 第三轮 | CoT 的图仍只有一根柱子；表格行名用了类别名（"算术"）而不是数据集名；读者希望单人格的尾巴指向图表时也有名字 | 表格行也给提示；"就近对齐"：数值在 ±1 或 ±2% 内时，对齐到论文表格行的精确值并引用该行；名字标签改为只要尾巴够不到说话人就显示 |
| CoT 重跑 | 第一版"就近对齐"把一根柱子对齐错了（见第 5 节），取消后收紧规则重跑 | 这次 GSM8K 图完整：标准提示 17.9、微调 GPT-3 55、思维链 56.9（+1.9），摘要题 100% |

## 5. 忠实度

- 所有图表数值都要能在论文原文中找到出处，差值由程序计算，不由模型计算。
- 剧本检查和事实核查之后，仍会删掉含有论文里没有的数字的句子。
- 一次教训：第一版"就近对齐"太宽松，把一根柱子对齐到了一句普通的话（GPT-3 在 SST-2 上的 54.3%），而正确值是 55，事实核查也没发现。我取消了那次任务（它还没开始画图），把规则收紧为：数值不完全相等时只能对齐到表格行，年份不算数字，没有论文原名时不对齐。然后重新跑了 CoT。
- 仍会出现的问题（语言模型写作层面）：
  - 偶尔有论文没说过的通俗说法，比如"旧模型会忘掉前面的词""每一步都会累积误差"。
  - 结尾偶尔声称"它答对了"，而论文并没有报告这个例子的输出。
  - 个别图表仍会漏掉最强的旧系统。
  - "超过人类"这类结论没有画出人类的数字。

  这些在报告的读者意见里都能看到，下一步见第 7 节。

## 7. 已知问题与下一步

1. **证据账本**：从 PDF 的几何位置读出表格，把图表绑定到已核实的数据上，并且总能带上整列里最强的对手。这能根治"漏掉最强对手"和"从图读数对不上"。
2. **结尾重画论文自己的图**：例如 Attention 图 3、图 4 的注意力连线，从矢量数据里读出强弱，配上论文原有的保留措辞。
3. **"超过人类"一类的对比**：必须把对手的数字（比如人类错误率 5.1%）画进同一张图。
4. **运行之间的波动**：同一篇论文多次运行，摘要题得分在 78% 到 100% 之间。可以让测验用 3 个读者投票，减少误判触发的不必要改写。
